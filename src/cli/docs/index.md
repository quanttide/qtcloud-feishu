YAML 注释里那套话语体系——「流程是数据，不是代码」「人是当前实情，不是应有形态」「流程升级的方向就是把执行者从人换成系统」——指向一个更大的目标：把组织流程做成可渐进自动化的数据结构。招聘只是第一个试验场。Rust 重写的深层动机可能不止「换个语言」，而是验证这套「数据定义 + 通用执行器 + 能力契约」的架构在新语言下是否依然成立。

作者本人不需要被提醒「流程是数据」——这是他自己做的决定。需要被说服、被教育的，是把来接手操作这套系统的人。这种自言自语式的注释，最常见的功能是为未来的交接预埋文档：等别人接手时，打开 YAML 能直接读到这套系统的设计哲学和当前边界。

目标形态是多用户（作者 + 非技术的操作者），当前形态是单作者的验证期，两者之间还隔着一道「接入真实飞书」的工序。

我们的直接目标就是要让日常的工作可以不走飞书的客户端走而是从我们自己搭的平台走，这样就意味着它是完全开放的。
